Radiografía de Chrome DevTools

Las herramientas para desarrolladores que trae Google Chrome

¿Qué es Chrome DevTools?

Son unas herramientas que vienen dentro del propio Chrome y que sirven para ver qué está pasando en una página web. Con ellas puedes mirar y cambiar el HTML y el CSS en directo, buscar errores en el JavaScript, ver qué archivos se descargan y comprobar si la página va lenta. Lo mejor es que no hay que instalar nada.

Pulsa el botón y aparecerá un mensaje aquí y otro en la consola.

Más información

Cómo se abre

  • Con F12 o con Ctrl + Mayús + I (en Mac, Cmd + Opción + I).
  • Haciendo clic derecho en cualquier parte de la página y eligiendo Inspeccionar.
  • Desde el menú de Chrome: Más herramientas y luego Herramientas para desarrolladores.

Por qué está bien usarlo

  • Ya viene con Chrome, así que no hay que instalar nada.
  • Los cambios de HTML y CSS se ven al momento, sin recargar.
  • Puedes parar el JavaScript con breakpoints en vez de llenar todo de console.log.
  • Te avisa de problemas de rendimiento, accesibilidad o red antes de subir la web.

Extensiones que le añaden cosas

  • React Developer Tools y Vue.js devtools, para ver los componentes de esos frameworks.
  • Lighthouse, que ya viene incluido y hace auditorías de la página.
  • axe DevTools, para revisar la accesibilidad con más detalle.

    Cliente y servidor

    El servidor local solo manda los archivos: index.html, el CSS y los módulos de JavaScript. Todo lo demás lo hace el navegador, que es el cliente: lee el HTML, aplica los estilos, carga los módulos que importa main.js y ejecuta el código de los botones, las tarjetas y el buscador. En la pestaña Red de DevTools se ve cómo se pide cada archivo y que todos devuelven un 200.
