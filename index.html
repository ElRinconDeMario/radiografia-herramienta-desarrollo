Las herramientas de desarrollo integradas en Google Chrome

¿Qué es Chrome DevTools?

Chrome DevTools es un conjunto de herramientas para desarrolladores web integrado directamente en el navegador Google Chrome. Permite inspeccionar y modificar el HTML y el CSS en tiempo real, depurar JavaScript, analizar las peticiones de red y medir el rendimiento de una página sin instalar nada adicional.

Pulsa el botón para ver un mensaje aquí y otro en la consola.

Información ampliada

Cómo abrir DevTools

  • Tecla F12 o Ctrl + Mayús + I (en macOS, Cmd + Opción + I).
  • Clic derecho sobre cualquier elemento y elegir Inspeccionar.
  • Menú de Chrome → Más herramientas → Herramientas para desarrolladores.

Ventajas

  • Viene incluido en Chrome: no requiere instalación.
  • Los cambios en HTML y CSS se ven al instante, sin recargar la página.
  • Permite depurar JavaScript con puntos de interrupción en lugar de llenar el código de console.log.
  • Ayuda a detectar problemas de rendimiento, accesibilidad y red antes de publicar.

Extensiones que lo amplían

  • React Developer Tools y Vue.js devtools: añaden paneles para inspeccionar componentes.
  • Lighthouse: viene integrado y genera auditorías de calidad de la página.
  • axe DevTools: análisis de accesibilidad más detallado.

Características principales

    Cliente y servidor

    El servidor local se limita a entregar archivos estáticos: index.html, la hoja de estilos y los módulos JavaScript. El cliente (el navegador) interpreta el HTML, aplica el CSS, descarga los módulos que importa main.js y ejecuta todo el código de interacción: eventos, generación de tarjetas y filtrado. En la pestaña Red de DevTools se comprueba que cada archivo se pide al servidor y responde con estado 200.
